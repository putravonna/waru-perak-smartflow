WARU-PERAK SMARTFLOW - PANDUAN WINDOWS

Akun demo:
  Nama pengguna: operator
  Kata sandi: smartflow123

Cara menjalankan:
1. Ekstrak file ZIP ke folder yang mudah ditemukan, misalnya Documents.
2. Pastikan Python telah terpasang.
3. Klik dua kali run_windows.bat.
4. Tunggu proses selesai. Browser akan membuka aplikasi, biasanya di http://localhost:8501.
5. Login dengan akun demo di atas.
6. Untuk menghentikan aplikasi, kembali ke jendela terminal lalu tekan Ctrl+C.

File utama:
- app.py: kode aplikasi
- requirements.txt: daftar paket yang diperlukan
- run_windows.bat: skrip untuk memasang paket dan menjalankan aplikasi
- smartflow.db: dibuat otomatis saat aplikasi pertama kali berjalan; menyimpan data lokal

Catatan penting:
Ini prototipe akademik/lokal. Aplikasi tidak terhubung ke CCTV, sensor, GPS, atau sistem resmi operator jalan tol. Data perlu dimasukkan secara manual. Akun demo tidak aman untuk deployment publik.
